# ADR-013: API foundation choices (NestJS 12, Prisma 7, DB-enforced history)

**Status:** accepted
**Context:** API-1. ADR-001 fixes NestJS + Prisma + PostgreSQL. This records the choices made while building the skeleton.

## Decisions
1. **ESM + explicit `@Inject()`.** The workspace is ESM with `verbatimModuleSyntax`. Nest's `emitDecoratorMetadata` conflicts with that, and Vitest does not emit it. Every constructor dependency uses `@Inject(Token)`, so DI works under `tsc`, `tsx` and Vitest without loosening the strict base config. Only `experimentalDecorators` is added (apps/api only).
2. **Prisma 7 + `@prisma/adapter-pg`.** Prisma 7 requires a driver adapter and `prisma.config.ts`. The client is generated into `src/prisma/generated` (gitignored) with `importFileExtension = "js"`. `$connect()` is lazy with the adapter, so `PrismaService.onModuleInit` runs a real query: the API refuses to start without a database.
3. **History immutability lives in the database.** `PolicyVersion` (immutable) and `AdminAuditEvent` (append-only) reject UPDATE, DELETE and TRUNCATE through triggers, so a buggy service cannot rewrite them (security invariant 9). *Limit:* the table owner or a superuser can drop triggers; this is accountability, not tamper-proofing. A project's policy therefore cannot be deleted while versions exist (`Restrict`).
4. **Global memberships** (`projectId` NULL) are deduplicated by a partial unique index, because Postgres treats NULLs as distinct in the Prisma `@@unique`.
5. **OpenAPI** is generated by `@nestjs/swagger`. Contracts are Zod, so route docs are written per route for now; a Zod-to-OpenAPI bridge is deferred until routes with bodies exist (API-2/3).
6. **Seed has no credentials.** Argon2id lands in API-2, so seed users and the seed device carry explicit non-loginable placeholders.
7. **Alert models** are left to API-8; exception tables hold the minimum for API-6, which may extend them.
8. **Dev container.** `apps/api/Dockerfile` is a development image (keeps dev dependencies to run `migrate deploy` at start); it is not a hardened production image.

## Consequences
Tests need a local Postgres (`pnpm db:up`); they create and drop their own `devguard_test` database and refuse non-local hosts.
